# Reflection: REST Persistent Data API

For my first assignment I designed and implemented a Flask REST API to accept patient health records and store them in a database (SQLite) and as a log file (JSONL). First, I built the Python environment and installed Flask, SQLAlchemy and Pydantic. Next, I designed the ClinicalData database model, and created fields to capture patient information including: Age, Blood Pressure, Heart Rate and Temperature. I then added validation of the input information using Pydantic, and designed POST and GET endpoints for the API to record and retrieve patient health data respectively.

While building this API I realized that a record could be stored in different formats to serve different purposes. As I added the ability for validation, database persistence, and logging to a JSONL file to my code, I came to better appreciate how APIs, schemas, and persistent storage work in concert. In future assignments I would like to better understand how to address consistency of multiple storage formats when the design fails.
